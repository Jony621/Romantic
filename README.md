# For My Love — Romantic Website

A responsive pink-themed romantic website with a clickable heart and a step-by-step love story.

## Run it
1. Extract `for_my_love_website.zip`.
2. Open `index.html` in a modern browser.
3. Click the heart, then use **Next little secret** to move through the messages.

## Customize
- Edit the messages and headings in `script.js` inside the `story` array.
- Change colors, fonts, spacing, and animations in `style.css`.
- The site is static and needs no installation or server.

Note: Browser click interactions use JavaScript (not Java). Java is typically used for a backend; it is not run directly in a standard browser page.
